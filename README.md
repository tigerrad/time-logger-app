# تایم لاگر — کورش شیراز

اپلیکیشن اندروید برای مدیریت زمان، اهداف، پس‌انداز، نشریات، جلسات و گزارش‌گیری.

## ساختار

- **تب ۱: تایم‌ترکینگ** — تایمر زنده و ثبت دستی زمان
- **تب ۲: اهداف** — اهداف روزانه تا ۵ ساله
- **تب ۳: پس‌انداز** — پیگیری پس‌اندازها
- **تب ۴: جلسات** — مدیریت جلسات با لینک
- **تب ۵: گزارش‌ها** — گزارش ساعتی و درصدی

## ساخت APK

GitHub Actions خودکار APK می‌سازد. از تب Actions آن را دانلود کنید.
